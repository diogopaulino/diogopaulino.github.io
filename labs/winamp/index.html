Como a trilha é feita

Nenhum áudio é baixado: as faixas demo são chiptune sintetizado na hora pela Web Audio API — ondas quadradas, triângulo e ruído renderizadas em um buffer PCM, exatamente como um tracker dos anos 90. Arraste seus próprios MP3/WAV para a janela e eles entram na mesma playlist.

Créditos
