Escolha um jogo e divirta-se

Videogame retrô direto no navegador. Toque ou clique na capa para ligar o console.

  1. 1Escolha um jogo na lista.
  2. 2Quando abrir, aperte START para começar.
  3. 3Ande com as setas e use A, B e C para pular e atacar.
  4. 4Para pausar, salvar ou sair, abra o menu.
↑↓←→ Andar
A S D A B C
Enter START
Esc P Menu / pausa
F Tela cheia
Shift SELECT

Na tela de toque: direcional à esquerda, botões A, B e C à direita e ⏸ para abrir o menu. Não precisa de teclado.

A biblioteca online está fora do ar agora. As capas aparecem, mas os jogos não baixam. Você ainda pode jogar um arquivo seu em Abrir jogo do computador.
